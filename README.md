# 🎹 Sintetizador Front-End 

Este é um projeto de um **Sintetizador Musical Interativo** desenvolvido com tecnologia web. O objetivo principal é criar um instrumento musical digital, explorando a geração de áudio por meio de código e criando uma interface tridimensional.

🚀 **[CLIQUE AQUI PARA TESTAR O PROJETO AO VIVO] (https://rodrigogouveiia.github.io/SINTETIZADOR_FRONT-END/)**

---

### Tecnologias Utilizadas
* **HTML5:** Estruturação semântica e armazenamento de frequências Hertz via atributos `data-nota`.
* **CSS3:** Design moderno em modo escuro, alinhamento flexível com Flexbox e animações mecânicas de profundidade ao pressionar as teclas.
* **JavaScript (ES6):** Uso da **Web Audio API** para gerar ondas sonoras (`sine`), controle dinâmico de ganho de volume exponencial (`exponentialRampToValueAtTime`) e manipulação de eventos do teclado físico do computador.

---

### Como Jogar / Testar
Você pode tocar o piano de duas formas:
1. Clicando diretamente nas teclas virtuais com o mouse.
2. Utilizando as teclas correspondentes no teclado do seu computador: **A, S, D, F, G, H, J**.
